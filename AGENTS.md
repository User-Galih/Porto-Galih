# Konfigurasi Agent (Repository Rules - Porto-Galih)

## 1. Integrasi AI & LLM Utama (Google AI Studio / Gemini API Pro)
- Proyek dan ekosistem ini telah beralih penuh dari 9Router ke **Google AI Studio (Gemini API Pro)**.
- Gunakan SDK resmi terbaru Google GenAI (`google-genai` untuk Python / `@google/genai` untuk JS/TS) dan variabel environment `GEMINI_API_KEY`.

## 2. Hierarki Skill UI/Frontend & Portofolio
1. **`antislop` Suite = HUKUM TERTINGGI (Primary Hard Gate & Filter Utama)**
   - Ikuti panduan di `DESIGN.md` pada root repositori ini.
   - Patuhi seluruh aturan `R-01` s/d `R-40` (tanpa karakter em-dash, tanpa klaim/angka palsu, wajib kontras WCAG AA `R-25`, batas dosis glassmorphism `R-10`, larangan script penambal CSS `R-33`, dan wajib verifikasi *Delivery Gate* `R-35`).
2. **`ai-engineer-blueprint` = Standar Konten Proyek AI**
   - Setiap proyek Flagship wajib menampilkan **5 Pilar Blueprint**: Fungsi Teknis, Kegunaan Bisnis, Target Pengguna, *Layman Proof of Success* (bukti 10 detik untuk orang awam), dan *Engineering Evaluation Matrix* (metrik evaluasi & ablation study).
3. **`design-taste-frontend` & `redesign-existing-projects` = Referensi Teknis Pendukung**
   - Digunakan untuk penyempurnaan tata letak responsif dan tipografi selama tidak bertentangan dengan aturan `antislop`.
